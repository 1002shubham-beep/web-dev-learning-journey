# Web Dev Learning Journey

My first steps in web development, from plain HTML to CSS layouts to JavaScript. This repo holds the exercises, practice pages and small projects I built while learning.

**Heads up:** this is old learning code. Some of it is messy and some projects are unfinished. I'm keeping it as a record of where I started.

## Repo structure

```
web-dev-learning-journey/
├── html/         # Page structure, text, images, lists, tables
├── css/          # Selectors, box model, Flexbox, Grid, animations, responsive design
└── javascript/   # Basics, DOM, events, async code, Fetch API
```

## How to run

No setup needed for the HTML and CSS pages. Clone the repo and open any `index.html` in your browser:

```bash
git clone https://github.com/<your-username>/web-dev-learning-journey.git
cd web-dev-learning-journey
```

Plain JavaScript files can be run with [Node.js](https://nodejs.org):

```bash
node "javascript/Loops/index.js"
```
